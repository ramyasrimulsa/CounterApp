# Native Android Counter Application

A lightweight, native Android application built to demonstrate fundamental state management, activity lifecycles, and event handling. This project marks my initial transition into the Android ecosystem utilizing Kotlin.

## 📱 Features
* **Dynamic State Management**: Tracks and increments an integer count value in real-time.
* **Event-Driven Architecture**: Uses click listener callbacks to update UI components instantly.
* **Device-リンク Tested**: Successfully deployed and validated on physical hardware via USB debugging tools.

## 🛠️ Tech Stack & Concepts
* **Language**: Kotlin (Statically typed, leveraging type inference)
* **IDE**: Android Studio
* **Layout Engine**: Android XML Views (`LinearLayout`)
* **Build System**: Gradle (Kotlin DSL)

## 🐍 Python Developer Insights
As a developer transitioning from Python, this project helped map cross-ecosystem concepts:
* **MainActivity.kt**: Acts similarly to initializing instance variables and setting up view-routing states in frameworks like Django or Tkinter.
* **activity_main.xml**: Structured hierarchy analogous to HTML DOM or configuration layers for layout management.
